# PII Redactor

Paste text (or drop a .txt/.csv/.md/.json/.log file) and get a copy with personal information removed.
Live at https://pii.xeej.app.

Everything runs in the browser. The page's Content Security Policy only allows network requests to this site and to
Hugging Face (to download the optional AI model's files once); the text you redact is never sent anywhere.

## Detection engines (use any combination)

| Engine | What it is | Cost |
| --- | --- | --- |
| Built-in patterns | Hand-written regexes with Luhn/IBAN checksums: emails, phones, cards, SSNs, IPs, dates, street addresses, ZIP/UK postcodes, API keys, names after Mr./Dear/Name:. | Instant |
| Presidio rules | The 52 English pattern recognizers from [Microsoft Presidio](https://github.com/microsoft/presidio) ported to JavaScript: regexes, checksum validators and context-word scoring. Gives identical results to presidio-analyzer 2.2.366's pattern recognizers on our test corpus. | Instant |
| GLiNER2 AI model | [fastino/gliner2-privacy-filter-PII-multi](https://huggingface.co/fastino/gliner2-privacy-filter-PII-multi) via the [okasi ONNX Q4 export](https://huggingface.co/okasi/gliner2-privacy-filter-pii-multi-onnx), run with onnxruntime-web in a Web Worker. Finds names, addresses, emails, phones, ID numbers, URLs and usernames in free text, in 7 languages. | ~470 MB one-time download (kept in Cache Storage), about 1 to 2 s per page of text on a laptop |

Results from all engines are merged; overlapping finds of the same type are combined, and the "What was found" table
shows which engine found each item.

## Files

- `index.html`, `app.js`: the page and the pattern engine, merging and redaction.
- `presidio.js`: Presidio's validators and scoring. `presidio-data.js` is generated by `scripts/build_presidio.py`.
- `gliner2.js`: a JavaScript port of GLiNER2's input preprocessing (gliner2 1.3.1 `SchemaTransformer`) and span
  decoding, so the ONNX graph runs without Python. Verified against the export's reference output.
- `worker.js`: downloads, caches and runs the model.
- `vendor/`: onnxruntime-web 1.30.0 (MIT) and @huggingface/tokenizers 0.2.0 (Apache-2.0).

No build step: it's static files. Detection is never perfect; review the output before sharing.
